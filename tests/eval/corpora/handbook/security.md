# Security

## Accounts
Every account must use the company password manager, and passwords are never shared, not
even with your own manager. Two-factor authentication is mandatory on email, source control
and the cloud console.

## Devices
Laptop disks must stay encrypted; the IT portal reports any machine where encryption has
been turned off. Screens lock after five minutes of inactivity and this setting cannot be
changed locally.

## Phishing
Forward suspicious email to the security team as an attachment rather than inline, so the
headers survive. Never reply to confirm whether a message is genuine, and never approve a
login prompt you did not trigger yourself.
